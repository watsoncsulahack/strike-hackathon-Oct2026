# DRMZ Paper Hands — documentation handoff

A proposed DRMZ educational web app where beginners learn perpetuals through virtual trading, contextual Morpheus guidance, and XP for demonstrated understanding. The target is a responsive progressive web app for laptop and phone, with a guided first task that introduces tools gradually.

**Start with [design.md](design.md).** This is the single agent-ingestion brief containing the business concept, mission statement, problem/solution statements, value proposition, dark/light themes and design tokens, user and system requirements, trade workflow, and prioritized implementation backlog.
