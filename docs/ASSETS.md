# Branding and asset provenance

This publication includes provenance notes only. Images, app icons, theme comparison, video, and binary checksum manifest are deferred. Paths below describe the prepared local package, not files in this commit.

The app adapts [DRMZ](https://www.drmz.app/) branding for a proposed educational experience. No formal DRMZ design-system approval or partnership is implied.

| Asset | Source and use |
| --- | --- |
| `skeleton-ui/assets/logo.png`, `reference-prototype/public/logo.png` | DRMZ artwork, [DRMZNEW24.png](https://github.com/rodg-drmz/web3ie-media-assets/blob/main/Web3%20In%20Education%20Courses/AI%20Demystified%20Course/DRMZNEW24.png) |
| `icon-192.png`, `icon-512.png` in the same folders | Resized app-icon derivatives from DRMZ artwork prepared for the earlier concept |
| `media/DRMZ-Concept-Ad.mp4` | Previously prepared DRMZ design concept, 40s, 1080p, with audio; illustrative UI, not live integration evidence |
| `media/Theme-Comparison.png` | Previously prepared dark/light concept comparison; a visual reference, not an exact screenshot of this skeleton |

Navy `#0E1A34`, lavender `#B9AFD6`, and gold `#FCEBA9` were sampled from published logo artwork. Light-theme roles, supporting colors, spacing, and typography are product proposals. The live website stylesheet was not extracted; do not describe these as exact CSS from drmz.app. Additional Cardano artwork referenced in the brief is [DRMZ -14.png](https://github.com/rodg-drmz/web3ie-media-assets/blob/main/Web3%20In%20Education%20Courses/AI%20Demystified%20Course/DRMZ%20-14.png).

Keep brand credit with reused assets. The repository's existing software license does not by itself establish permissions for third-party trademarks or media. Public release of a new promotional cut should retain a record of asset and audio permissions. Concept media publication is deferred; these notes do not assert new rights.

The deferred `media/checksums.json` records file sizes and SHA-256 hashes for verifying that the supplied media was transferred intact.
