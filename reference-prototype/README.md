# Earlier technical prototype — source deferred

This note is published as documentation only. Prototype source, UI assets, scripts, package configuration, and tests are not included in this commit. The instructions below apply after source publication.

This is the earlier DRMZ Paper Hands dashboard-first implementation, retained for its paper engine, read-only adapter, lessons, and PWA shell. Its opening dashboard is **superseded by the guided discovery direction in `../design.md`**. Once the source is available, start UI work in `../skeleton-ui/`.

From the repository root, run `npm run build`, `npm test`, then `npm run dev:reference`. The local Node server invokes the same Fetch-based Worker handler and serves its embedded assets. No original hosting project IDs, deployment bindings, private environment values, or credentials are needed or included.

The public Strike API routes are observational. All orders are calculated in the browser's virtual ledger. Tests use fixtures and mock fetch, not a live exchange. Public API compatibility and browser QA must still be verified. The 8-decimal engine, educational isolated-loss cap, unbooked funding, and missing venue liquidation are documented in `../design.md`.

`worker/index.js` and `src/themes.css` are generated by `scripts/assemble.mjs` and should not be edited directly. Both themes and the brief are read from the root `design.md`.
